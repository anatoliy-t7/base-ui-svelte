This project is an **unofficial** community port. Issues and PRs should go to the [base-ui-svelte](https://github.com/anatoliy-t7/base-ui-svelte) repository.

For Base UI React community resources (Discord, discussions, styled libraries), see [Base UI Community](https://base-ui.com/react/overview/community).

When reporting bugs, note whether the behavior differs from Base UI React and link the relevant component demo on this docs site.
