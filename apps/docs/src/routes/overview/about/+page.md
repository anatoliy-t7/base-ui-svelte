**base-ui-svelte** reimplements Base UI–inspired APIs and accessibility behavior for Svelte 5. It is **not affiliated** with MUI or the Base UI team.

For product philosophy and broader context, see upstream [Base UI About](https://base-ui.com/react/overview/about) and this site’s [Community](/overview/community) page.

Svelte-specific install and divergence notes live in [Quick start](/) and [Differences](/handbook/differences).
